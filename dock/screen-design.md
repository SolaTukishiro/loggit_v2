# 4. 画面詳細

## SCR-001 ログイン

### 目的

登録済みユーザーがログインする。

### 項目

|項目|必須|
|---|:---:|
|メールアドレス|✅|
|パスワード|✅|

### ボタン

- ログイン
- 新規登録

### バリデーション

- 必須入力
- 認証失敗時はエラーメッセージ表示

### ワイヤーフレーム

```text
+--------------------------------+
|           Loggit               |
|                                |
| メールアドレス                 |
| [__________________________]   |
|                                |
| パスワード                     |
| [__________________________]   |
|                                |
|      [ ログイン ]              |
|                                |
| 新規登録はこちら               |
+--------------------------------+
```

```text
・React学習

[新規投稿]
------------------------------------
```

# 5. 共通エラーメッセージ

|ケース|表示|
|---|---|
|必須未入力|入力してください|
|認証失敗|メールアドレスまたはパスワードが違います|
|権限なし|この操作はできません|
|404|ページが存在しません|
|500|システムエラーが発生しました|
